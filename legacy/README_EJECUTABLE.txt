===============================================
    TRANSCRIPTOR DE AUDIO AI - EJECUTABLE
===============================================

🎯 ARCHIVOS INCLUIDOS:
- transcriptor-audio-ai-final.exe (Aplicación principal - 41.4MB)
- .env                            (Configuración de API keys)
- start-app.bat                   (Script de inicio fácil)
- INSTRUCCIONES_EJECUTABLE.md     (Guía completa)
- README_EJECUTABLE.txt           (Este archivo)

🚀 INICIO RÁPIDO:
1. Configura tu API key de Gemini en el archivo .env
2. Ejecuta start-app.bat (recomendado) o transcriptor-audio-ai.exe
3. Abre http://localhost:3001 en tu navegador
4. ¡Listo para transcribir!

⚙️ CONFIGURACIÓN OBLIGATORIA:
Edita el archivo .env y reemplaza:
API_KEY_GEMINI=your_gemini_api_key_here

Por tu API key real de Google Gemini:
API_KEY_GEMINI=tu_api_key_real_aqui

📋 OBTENER API KEY DE GEMINI:
1. Ve a: https://makersuite.google.com/
2. Crea cuenta o inicia sesión
3. Genera una API key gratuita
4. Cópiala al archivo .env

🎵 FORMATOS SOPORTADOS:
- MP3, WAV, M4A, OGG
- Máximo 25MB por archivo

🤖 MODELOS DISPONIBLES:
- Gemini 2.5 Flash (Recomendado) - Rápido
- Gemini 2.5 Pro - Análisis avanzado

✨ CARACTERÍSTICAS:
✅ Transcripción nativa con Gemini 2.5
✅ Instrucciones personalizadas
✅ Drag & drop de archivos
✅ Copia y descarga de resultados
✅ Interfaz moderna y responsive
✅ Ejecutable independiente (no requiere instalación)

🔧 SOLUCIÓN DE PROBLEMAS:
- Si no carga el CSS: Refresca la página (F5)
- Si hay error de API: Verifica tu API key en .env
- Si el puerto está ocupado: Reinicia la aplicación

📞 SOPORTE:
La aplicación funciona completamente offline una vez iniciada,
solo requiere internet para las llamadas a la API de Gemini.
